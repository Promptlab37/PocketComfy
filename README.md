# 🎬 PocketComfy by PromptLab

### Celé AI studio v kapse, poháněné tvým vlastním počítačem

**Video · Obrázky · Úpravy · Zvětšení · Hudba · Hlas · 3D**

Androidí appka, která z telefonu ovládá tvůj vlastní server ComfyUI.
Žádný cloud, žádné předplatné: telefon je dálkové ovládání počítače s grafickou kartou.

## Co appka umí

- **Video**: z obrázku nebo z textu, dlouhé video navazujícími úseky, mluvící scéna s hlasem
- **Obrázky**: tvorba z textu, úpravy, rozšíření, výměna tváře, oprava starých fotek
- **Zvětšení** obrázků i videí
- **Hudba** a **hlas**
- **3D model** z fotky

Appka potřebuje vlastní počítač se serverem ComfyUI a výkonnou grafickou kartou.
